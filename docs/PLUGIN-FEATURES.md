# Native feature mapping

These are native implementations of the source plugins' behavior. TidaLuna, Electron, browser DOM observers, and plugin JavaScript are not loaded. The original repositories remain the authoritative descriptions; their current branches were inspected during development.

| # | Source plugin | Native implementation and limits |
|---|---|---|
| 1 | [OneClickLyrics](https://github.com/Foukapik/TidaLuna-Plugins/tree/master/plugins/One%20Click%20Lyrics) | Player lyrics control and Ctrl+L open the focused lyrics view. |
| 2 | [Custom Fonts](https://github.com/jxnxsdev/luna-plugins/tree/main/plugins/CustomFonts) | Load a local font through Settings. Segoe UI is used by default. No CSS injection or font-scanning service. Complex shaping and broad CJK coverage depend on the chosen font/egui support. |
| 3 | [Lyrics Everywhere](https://github.com/jxnxsdev/luna-plugins/tree/main/plugins/LyricsEverywhere) | Current-line capsule on library pages plus a separate native, always-on-top window. That child's RAM is included in diagnostics. CatJam integration is specific to the upstream client and is not included. |
| 4 | [Total Play Time](https://github.com/jxnxsdev/luna-plugins/tree/main/plugins/TotalPlayTime) | Queue duration includes the unplayed portion of the current track and all remaining tracks, calculated from metadata and consumed PCM time. |
| 5 | [Colorama Lyrics](https://github.com/meowarex/TidaLuna-Plugins/tree/main/plugins/colorama-lyrics-luna) | User-selected lyric accent/color and active/inactive contrast, sharing the lyrics renderer. |
| 6 | [Copy Lyrics](https://github.com/meowarex/TidaLuna-Plugins/tree/main/plugins/copy-lyrics-luna) | Copy complete lyrics or a single line from its context menu. Arbitrary drag-selection-to-auto-copy behavior is not reproduced. |
| 7 | [Element Hider](https://github.com/meowarex/TidaLuna-Plugins/tree/main/plugins/element-hider-luna) | Persistent native controls hide the sidebar, covers, format badges, and related overlays. There is no DOM or arbitrary CSS-selector picker. Settings remain reachable with Ctrl+,. |
| 8 | [Cover Fetcher](https://github.com/SinnerK0N/tidaluna-plugins/tree/master/plugins/CoverFetcher) | Save 1280px TIDAL cover art or copy its link from a track context menu. Missing covers fail explicitly. |
| 9 | [NoBuffer](https://github.com/Inrixia/luna-plugins/tree/master/plugins/NoBuffer) | A background downloader, bounded decoder queue, and limited safe Range retries recover stalls without network work on the audio callback. This adapts the original CDN-warming intent; it does not redundantly download a second copy of every stalled track. |
| 10 | [NoPlaylistBackgroundImage](https://github.com/SuperslowJelly/TIDAL-Clear-Coat/tree/main/plugins/NoPlaylistBackgroundImage) | Artwork behind playlist views is independently switchable and disabled by default. |
| 11 | [RealMAX](https://github.com/Inrixia/luna-plugins/tree/master/plugins/RealMax) | Prefer a higher-quality catalog match with the same ISRC, explicit flag, and near-identical duration. Never substitutes a different recording by title alone. The decoded result is checked independently; unavailable higher-quality versions remain unavailable. |
| 12 | [Song Downloader](https://github.com/Inrixia/luna-plugins/tree/master/plugins/SongDownloader) | Individual/playlist sequential downloads, cancellation after the current track, disk streaming, collision checks, and native FLAC title/artist/album/ISRC/link tags. TIDAL must authorize the offline request. MP4 tagging, cover embedding, arbitrary naming templates, and unsupported DRM types are not implemented. |
| 13 | [Tidal Tags](https://github.com/Inrixia/luna-plugins/tree/master/plugins/TidalTags) | Catalog quality tags in rows and decoded codec/bit-depth/sample-rate signal details during playback. It does not prefetch every catalog track's exact format, avoiding large request/cache overhead. |
| 14 | [TidalLyricsTranslate](https://github.com/FireWall-code/TidaLuna-Plugins/tree/master/plugins/lyrics-translate) | On-demand translation or romanization from Settings, original/translated toggle, preserved line timestamps, repeated-line deduplication. Google's unofficial endpoint can rate limit or change. Translations are retained for the current track; provider-specific persistent translation caching and all upstream display combinations are not reproduced. |
| 15 | [Radiant Lyrics](https://github.com/meowarex/TidaLuna-Plugins/tree/main/plugins/radiant-lyrics-luna) | Whole-line highlighting, color and glow, smooth scrolling, and a frosted artwork backdrop. Lyrics come from TIDAL, LRCLIB, local LRC files, or the existing cache. |
| 16 | [CoverTheme](https://github.com/Inrixia/luna-plugins/tree/master/plugins/CoverTheme) | Palette extraction from a small cover thumbnail, cached frosted backdrop and restrained accent theme. Effects can be lowered or disabled. |

All native options can be enabled at once. That does not make account permissions, unavailable lyric timestamps, translation-provider availability, or offline rights appear magically. Validation records the actual active integrations. The complete sixteen-feature live TIDAL scenario remains unverified until those live checks pass.


### Native controls (1 November 2026)

Settings > Plugins groups the native features with individual switches and parameter editors. Disabling download, cover-fetch, copy-lyrics or one-click controls removes/disables their corresponding entry points; total-duration and tags switches control the displayed metadata. Font enablement preserves the chosen file, validates font data and restores the system family when disabled. Translation is explicitly requested from this panel and does not send lyric text just because settings is opened. Profile photos are local Undertow customization, not a TIDAL profile write. See README and the latest VALIDATION entry for the exact tested scope.
