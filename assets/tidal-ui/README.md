# TIDAL desktop typefaces

The regular, medium, and demibold Nationale faces come from the desktop assets of TIDAL 2.48.0. The project owner confirmed authorization to reproduce the desktop interface and its UI elements in Undertow.

The files were converted from the installed WOFF assets to TrueType for the native renderer. The original font names, outlines, and copyright notices are retained. Undertow uses these faces for its default UI and retains the existing custom-font and system fallback paths.
